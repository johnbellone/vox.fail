# Controls

These are the default controls. Each button is named for the action it does. You can change
them in the controls menu (press Esc to open the menu).

## Keyboard and mouse

| Action | Default |
| --- | --- |
| Walk forward, back, left, right | W, S, A, D |
| Jump (fly up while flying) | Space |
| Sneak (fly down while flying) | Left Shift |
| Sprint | Left Ctrl |
| Break the block you aim at (hold) | Left mouse button |
| Place the block in your hand, or use what you aim at | Right mouse button |
| Pick block (put the block you aim at in your hand) | Middle mouse button |
| Quick block | 1 to 9 |
| Next or previous quick block | Mouse wheel |
| Block wheel (hold, point with the mouse, let go to take a block or prop) | Tab |
| Emote wheel (hold, point with the mouse, let go to play the emote) | G |
| Fly | F |
| Inventory | E |
| Change view (first person, behind the shoulder, from above) | F5 or V |
| Menu (pause; also backs out of a menu) | Esc |
| Push to talk (hold to send voice) | B |
| Voice channel (switch between nearby and party) | N |

You start in first person: look around with the mouse (the first click captures it). The mouse
wheel cycles the quick blocks. There is no hotbar: what is in your hand shows bottom right.

### From above

Press V or F5 to change the view: first person, behind the shoulder, then from above. From
above, the mouse is a pointer instead:

- Left click walks to the point under the pointer.
- Right click places a block; Shift + right click removes one.
- The wheel zooms; Shift + wheel changes the quick block.
- Q and R turn the view.

## Controller

Buttons are named by position. The names on screen match the brand of your controller:
Xbox (A, B, X, Y; LB, RB, LT, RT), PlayStation (cross, circle, square, triangle; L1, R1, L2, R2),
Nintendo (B, A, Y, X; L, R, ZL, ZR), and Steam (A, B, X, Y). Other pads use the Xbox names.

| Action | Default button |
| --- | --- |
| Walk | Left stick |
| Look and turn the camera | Right stick |
| Jump (fly up while flying) | South (bottom face button) |
| Sneak (fly down while flying) | Right stick click |
| Sprint | Left stick click |
| Break the block you aim at (hold) | Right trigger (RT) |
| Place the block in your hand, or use what you aim at | Left trigger (LT) |
| Pick block | West (left face button) |
| Block wheel (hold, point with the right stick, let go to take a block or prop) | Left bumper (LB) |
| Emote wheel (hold, point with the right stick, let go to play the emote) | Right bumper (RB) |
| Fly | D-pad down |
| Change view | D-pad up |
| Inventory | North (top face button) |
| Menu (pause) | Start |
| Push to talk (hold to send voice) | D-pad right |
| Voice channel (switch between nearby and party) | D-pad left |

While a wheel is open you stand still: the sticks and the mouse work the wheel. See
[Building](building.md) for the block wheel and [Emotes](#emotes) below.

Controls saved before the wheels came in are moved over once: the bumpers become the two wheels.
A button you had changed yourself stays as you set it.

In menus, the face button South confirms, East backs out, and the bumpers switch tabs.

Nintendo pads: with the Nintendo option in the menu on (it is off by default), the face buttons
swap: South and East, West and North. Then the right-hand button confirms and the bottom one backs out.

## Menus

| Action | Keyboard and mouse | Controller |
| --- | --- | --- |
| Confirm | Enter | South |
| Back | Esc or Backspace | East |
| Next tab | Tab or Page Down | Right bumper |
| Previous tab | Q or Page Up | Left bumper |
| Move through the menu | Arrow keys | D-pad or left stick |

## Emotes

Hold the right bumper (or **G**) for the emote wheel: eight emotes in a circle.

1. Point at an emote with the right stick or the mouse.
2. On a controller, push the left stick toward someone or something to face: the nearest
   player, prop or doorway that way, up to 16 m off, is named in the middle of the wheel. With
   the keyboard and mouse, it is the one nearest the middle of your view.
3. Let go. You turn to face it and play the emote. Walking stops it.

Everyone nearby sees it. Choose the eight on the **Emotes** screen of the menu (Esc, then
Emotes): **<** and **>** step each one through your character's animations. They are kept on
this device.
