# Decisions
* [Decision (superseded): Stay on Bevy 0.19.1](bevy-0-19-1-pin.md) - Superseded on 2026-11-27 by the owner-approved upgrade to Bevy 0.20.1; kept for history.
* [Decision: Keep vox-core Free of Bevy](core-without-bevy.md) - Shared game rules live in an engine-free crate so servers, clients and future pocket worlds run identical code.
* [Decision: 120 Hz Fixed Step with Interpolated Drawing](fixed-120hz-simulation.md) - Particles, crowd and effects step at a fixed 120 Hz and are drawn as a blend of the last two ticks, so motion is frame-rate independent.
* [Decision: Read Twitch Chat Anonymously](anonymous-twitch-irc.md) - Chat is read over IRC as the read-only justinfan user so streamers set only a channel name and authorise nothing.
* [Decision: Host vox.fail Behind a Cloudflare Tunnel](cloudflare-tunnel-hosting.md) - Cloudflared carries traffic to localhost services so the server needs no open ports or certificates; worlds answer on /w/<port>/ws.
* [Decision: Signed Tokens Instead of Server Call-backs](ed25519-signed-launch-tokens.md) - The directory signs a player's identity with Ed25519 so worlds verify it offline with only a public key.
* [Decision: Authority Cannot Be Sent](authority-not-transferable.md) - The shared currency can only be earned and spent on feats; tradeable value lives in per-world currencies.
* [Decision: IMA ADPCM for Network Voice (Opus Later)](adpcm-network-voice.md) - Show voice uses 16 kHz IMA ADPCM because it needs no C library; Opus can replace it behind a codec field.
* [Decision: Block Avatar Is Local-First, Voice-First, One Binary](local-first-single-binary-avatar.md) - The design principles of the streaming app: microphone drives everything, no account or cloud, every feature is a text command, failures are visible but not fatal.
* [Decision (done): Restructure into crates/, bins/ and apps/](restructure-into-crates-bins-apps.md) - The repository is a virtual workspace with libraries in crates/, programs in bins/ and Bun web apps in apps/; done and on main.
* [Decision: Haiku Writes, Sonnet Reviews, Beads Plan the Work](haiku-writes-sonnet-reviews.md) - Agent work is split into haiku-sized beads (one writer, under 100k tokens, named files, acceptance command) and every writer bead is reviewed by sonnet before the lead closes it.
* [Decision: Player Help Is Markdown in docs/help, Rendered by the Site](player-help-single-source.md) - The player help lives once, as markdown in docs/help/, and the site's /help page bundles those files at build time instead of copying the text.
* [Decision: Oxen Is the Snapshot Store, Squashed Daily](oxen-snapshot-store.md) - World snapshots can be commits in an Oxen repository driven through the oxen command line, with history older than a week squashed by rebuilding the repository.
* [Decision: Structures Have an Owner and Use, Copy and Edit Rights](structure-entitlements.md) - A structure has one owner who grants use, copy or edit to named accounts or opens it to everyone to use or copy; world servers check with the directory before placing one.
* [Decision: Props Come from Recipes and Imported MagicaVoxel Files](props-hybrid-authoring.md) - Prop art is authored two ways into one library: Rust recipes for most props, and hand-made MagicaVoxel files as first-class imports, both through the same checks.
* [Decision: Prop Behaviours Are a Closed Vocabulary, Never Code](props-closed-behaviours.md) - A prop can only do what a fixed list of declarative behaviours allows, so any prop is as safe to accept as a block and the server stays authoritative.
* [Decision: Props Are a Third Kind of Thing, Beside Blocks and Structures](props-third-kind-of-thing.md) - A prop has its own finer voxel grid, behaviours and versioned entity form; it is neither a block in chunk data nor a structure of blocks.
* [Decision: Upgrade to Bevy 0.20.1, and Stay There](bevy-0-20-upgrade.md) - On the owner's say-so (2026-11-27) the workspace moved from Bevy 0.19.1 to 0.20.1; further upgrades again need the owner's approval.
* [Decision: Voice Chat in Worlds (Nearby and Raid Party), Relayed by vox-server](world-voice-chat.md) - World voice reuses Block Avatar's IMA ADPCM voice in a new pure crate vox-voice, travels as droppable wire messages (PROTOCOL 7), and the world server alone decides who hears each packet.
* [Decision: Zones Are 256 m, Regions Are 32 x 32 Zones](zones-and-regions.md) - What used to be a region (16 x 16 chunk columns) is now a zone; a region is 32 x 32 zones (8,192 m, one atlas tile), stored as a hashed list of its zones' hashes.
* [Decision: Pull-Based Automatic Deploys from Version Tags](pull-based-auto-deploy.md) - A v* tag builds a release bundle in GitHub Actions; a systemd timer on the vox.fail server pulls, verifies, swaps a symlink, restarts, health-checks and purges Cloudflare's cache.
* [Decision: A Cloudflare Worker Shows an Offline Page When the Server Is Down](edge-worker-offline-page.md) - vox.fail runs on a dev server for now; a Worker on vox.fail/* passes requests through and serves a static marketing page (and a JSON 503 for /api) when the tunnel or directory can't be reached.
