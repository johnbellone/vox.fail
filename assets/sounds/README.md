# Sound effects

Real recordings, only trimmed, faded and levelled. All from the ESC-50 dataset (Karol Piczak,
github.com/karoldvl/ESC-50), using only clips whose Freesound originals are CC0 (public domain).

| File | Used for | Freesound original (sound ID), author |
|---|---|---|
| splat.wav | tomato hits | water_splash_10shots.wav (50623), vibe_crc |
| pop.wav | confetti | Soda Can Open.aif (144031), timgormly |
| knock.wav | a hat landing | Wood_Knocks_2.aif (103999), RutgerMuller |
| thud.wav | giant tomato, landing from a hop | Footsteps in Factory Hall on Wood and Concrete.wav (155858), RutgerMuller |
| applause.wav | raids and subs | Clapping, Medium Audience, slow to fast.wav (115920), issalcake |
| firework.wav | cheers (bits) | Fireworks - explode and fizz.wav (117615), soundmary |

Replace any of them with your own .wav of the same name (in your files folder's `sounds/`),
or turn them all off on the control page (Show tab, "Sound effects").
